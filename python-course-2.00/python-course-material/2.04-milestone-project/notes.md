# 2.4 Milestone Project

Sections 2.1 through 2.3 covered everything you need, classes, objects,
attributes, methods, special methods like `__str__`, composition, and the
one class per file convention. This section is a single hands on project
that puts all of it together.

This one's hands-on: read the project's own `notes.md` first, it guides
you through building each class yourself rather than handing you finished
code. A complete, working solution is included too, so once you've given
it a real attempt you can check your version against it or see how it's
done.
